NG Media Automation

Política de privacidad

Vigente desde el 21 de noviembre de 2026

Alcance

NG Media Automation es una herramienta interna del equipo de NG Media. No tiene usuarios externos: las únicas Cuentas de Google que autorizan la aplicación son las del propio estudio. Esta política describe que datos de Google usa la herramienta y como los trata.

Qué datos de Google se usan

La herramienta accede únicamente a los datos de las cuentas que la autorizan, y solo para la tarea que el equipo ejecuta en ese momento:

  • YouTube - datos de los canales propios del estudio (títulos, estadísticas públicas del canal) y subida de los videos producidos por el estudio a esos mismos canales.
  • Google Sheets - lectura de hojas de cálculo del propio estudio usadas como fuente de datos.
  • Google Drive - lectura y escritura de los archivos que la propia herramienta genera.
  • Otros servicios de Google Workspace - solo cuando el equipo concede ese permiso expresamente en la pantalla de consentimiento al autorizar.

La lista de permisos vigente es siempre la que Google muestra en la pantalla de consentimiento en el momento de autorizar.

Para qué se usan

Exclusivamente para ejecutar la tarea que el equipo pide: preparar, publicar y medir el contenido propio del estudio. Los datos de Google no se usan para publicidad, no se usan para crear perfiles, y no se usan para entrenar modelos de inteligencia artificial.

Con quién se comparten

Con nadie. Los datos de Google no se venden, no se alquilan, no se ceden a terceros y no se transfieren fuera de los sistemas del estudio. No hay acceso humano a esos datos más allá del propio equipo que ejecuta la herramienta.

Dónde se guardan y cuánto tiempo

Las credenciales de autorización (tokens de Google) se guardan cifradas en los equipos del estudio, nunca en un servidor público ni en un repositorio de código. Los datos leídos desde Google se usan durante la ejecución y se conservan solo como archivos de trabajo locales; se eliminan cuando dejan de ser necesarios.

Uso limitado

El uso y la transferencia de información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Cómo se revoca el acceso

Cualquier cuenta que haya autorizado la aplicación puede retirar el acceso en cualquier momento desde la página de permisos de la Cuenta de Google. Al revocarlo, la herramienta deja de poder acceder a los datos de esa cuenta de inmediato.

Contacto

Como la aplicación no se ofrece a terceros, no hay un canal de soporte público. El contacto de soporte del estudio es el que figura en la pantalla de consentimiento de Google en el momento de autorizar.

Sobre el dominio

Esta página se sirve en un subdominio de ng-boutique.com, un dominio operado por el mismo estudio. NG Media y NG Boutique son marcas del mismo equipo; el subdominio solo aloja estas páginas informativas y no forma parte de la tienda.

Cambios

Si esta política cambia, la fecha de vigencia que aparece arriba se actualiza en la misma edición.

English

Scope

NG Media Automation is an internal tool of the NG Media team. It has no external users: the only Google Accounts that authorize the application are the studio's own. This policy describes what Google data the tool uses and how it handles it.

What Google data is used

The tool accesses only the data of the accounts that authorize it, and only for the task the team is running at that moment:

  • YouTube - the studio's own channel data (titles, public channel statistics) and uploads of studio-produced videos to those same channels.
  • Google Sheets - reads the studio's own spreadsheets used as a data source.
  • Google Drive - reads and writes the files the tool itself generates.
  • Other Google Workspace services - only where the team expressly grants that permission on the consent screen at authorization time.

The list of permissions in force is always the one Google displays on the consent screen at authorization time.

What it is used for

Solely to run the task the team asks for: preparing, publishing and measuring the studio's own content. Google data is not used for advertising, not used to build profiles, and not used to train artificial-intelligence models.

Who it is shared with

No one. Google data is not sold, not rented, not disclosed to third parties and not transferred outside the studio's systems. There is no human access to that data beyond the team running the tool.

Where it is stored and for how long

Authorization credentials (Google tokens) are stored encrypted on the studio's own machines, never on a public server and never in a code repository. Data read from Google is used during execution and kept only as local working files; it is deleted once no longer needed.

Limited Use

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

How to revoke access

Any account that has authorized the application can withdraw access at any time from the Google Account permissions page. On revocation the tool immediately loses the ability to access that account's data.

Contact

Because the application is not offered to third parties, there is no public support channel. The studio's support contact is the one shown on Google's consent screen at authorization time.

About the domain

This page is served on a subdomain of ng-boutique.com, a domain operated by the same studio. NG Media and NG Boutique are brands of the same team; the subdomain hosts only these informational pages and is not part of the store.

Changes

If this policy changes, the effective date shown above is updated in the same edit.
